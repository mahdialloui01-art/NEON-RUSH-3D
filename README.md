# NEON RUSH 3D

Standalone futuristic 3D parkour game for Android, built with Godot 4.

## Project isolation
This repository is independent from BlockNova and any trading application. It uses its own project files and Android application ID: `com.neonrush.parkour`.

## Current status
Prototype source project. Android APK export and online multiplayer backend are not yet configured or verified.

## Controls
- Move: WASD / on-screen controls
- Jump: Space / Jump
- Sprint: Shift
- Slide: Ctrl

## Build
Open this project in Godot 4.x, install Android export templates, configure the Android SDK/JDK, then export an Android APK.
